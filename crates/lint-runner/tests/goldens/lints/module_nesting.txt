modules nest by use: a file used only inside one sibling belongs inside it:
src/helper.rs:1: used only from crate::parent; move it inside that module
src/reaching.rs:1: reaches into crate::outer::inner; import the parent's re-export instead
src/wide.rs:1: re-exports 9 items, at most 8 allowed; split the module
a struct with no logic of its own that one other file consumes is a parameter bag:
src/helper.rs:1: Tool only carries values into one other file; give it the logic that consumes it
src/outer/inner.rs:1: Thing only carries values into one other file; give it the logic that consumes it
